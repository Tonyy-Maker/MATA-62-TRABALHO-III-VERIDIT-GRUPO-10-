# ADR-0003: DISPONIBILIDADE

* Status: Aceito

## Contexto
Algumas publicações (stories, por exemplo) podem sumir ou ser apagadas em um período muito curto. Se o sistema estiver fora do ar na hora, o registro se perde para sempre.

## Decisão
Deve ser possível fazer um artefato a qualquer momento. Alternativas descartadas: janelas de manutenção programadas; implantação em uma única instância.

## Consequências
Serviços replicados e sem ponto único de falha no caminho de captura, com custo maior de infraestrutura. O Serviço de Captura é implantado e escalado separadamente dos demais.

## Notas
O Serviço de Captura é o mais crítico para este requisito.
