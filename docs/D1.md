# D1: TIPOS DE USUÁRIO CADASTRÁVEIS

* Status: Aceito

## Contexto
O sistema deve permitir o cadastro de advogados, usuários comuns e empresas, mas na primeira versão apenas advogados e usuários comuns são cadastrados.

## Decisão
O sistema permite o cadastro dos três tipos de usuário, e na primeira versão apenas advogados e usuários comuns são cadastrados. Alternativas descartadas: lançar já com os três tipos; cadastrar um único tipo genérico de usuário.

## Consequências
O Serviço de Contas modela o tipo de usuário como atributo extensível, e adicionar empresas depois não exige mudar os outros serviços.
